# Local Pulse privacy policy

_Last updated: October 20, 2026_

Local Pulse is a hackathon prototype built by GrowthPro AI. This policy covers the Local Pulse Alexa+ add-on and MCP server.

**What we process.** When you ask Local Pulse a question, Alexa+ sends the request to our server so we can answer it. The current version uses demonstration data only. It does not collect, store or sell personal information about you or your customers.

**Voice recordings.** Local Pulse never receives audio. Amazon handles voice input under the Alexa privacy policy.

**Review replies.** Replies are posted only after you explicitly approve them. In this prototype, posting is simulated.

**Retention.** Pending approvals are held in memory for up to 15 minutes and then discarded. Nothing is kept after the server restarts.

**Contact.** Questions: open an issue at https://github.com/pranjalvatsa/local-pulse/issues.
